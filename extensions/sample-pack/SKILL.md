# Sample Extension Pack

This is a minimal example of a Storia extension. It adds a single persona and a single workflow to demonstrate the extension layout.

## Personas Added

- **Dream Interpreter** — analyzes dream logic, surreal sequences, and symbolic subtext for literary and experimental narratives

## Workflows Added

- **W099 — Dream Sequence** — guides the generation of dream sequences with surreal logic, symbolic coherence, and narrative purpose

## Usage

This extension is not published. To use it locally, reference it from your Storia configuration:

```json
{
  "extensions": ["./extensions/sample-pack"]
}
```
