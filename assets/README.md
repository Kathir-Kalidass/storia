# Storia Assets

Supporting materials for the Storia Narrative Intelligence Platform.

## Contents

This directory holds supplementary assets that enhance or extend the core Storia experience:

- **Branding & Identity** — Storia name, logo, color palette, tone of voice
- **Reference Tables** — Quick-reference sheets for persona categories, workflow IDs, capability packs
- **Templates** — Reusable outlines and checklists for common storytelling tasks
- **Integrations** — Configuration helpers for LLM providers and agent frameworks

## Asset Types

| Directory | Purpose |
|-----------|---------|
| `branding/` | Visual identity, logos, style guides |
| `tables/` | Reference data (persona mapping, workflow index, confidence thresholds) |
| `templates/` | Outlines, checklists, proformas |
| `integrations/` | LLM provider configs, agent framework adapters |
