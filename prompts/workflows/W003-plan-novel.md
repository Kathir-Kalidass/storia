# W003: Plan Novel — Prompt Guidance

## Purpose
Create or revise a story outline: acts, scenes, arcs, and structure.

## Key Considerations
- Genre dictates act structure (fantasy: three-act with prologue/epilogue, thriller: four-act, romance: two-act)
- Each scene must have a clear purpose and advance something
- Subplots should connect to the main plot at minimum two points
- Character arcs should have identifiable starting points and growth trajectories

## Output Structure
1. Act breakdown with major turning points
2. Scene sequence with cause/effect chain
3. Subplot map showing touch points with main plot
4. Character arc outlines
