# W004: Build Character — Prompt Guidance

## Purpose
Create a complete character profile with personality, backstory, appearance, and arc.

## Required Fields
- Name, role in story, age, gender
- Personality traits (3-5 core traits)
- Core motivation and fear
- Internal flaw
- Backstory (relevant to the plot, not exhaustive biography)
- Appearance (distinctive enough to be memorable)
- Voice traits (vocabulary level, speech patterns, dialect)

## Optional Fields
- Relationships to existing characters
- Inventory / equipment
- Physical state baseline
- Knowledge boundaries (what they know at story start)

## Integrity Rules
- No duplicate character names
- Relationships must reference valid character IDs
- Character must be compatible with genre and world rules
