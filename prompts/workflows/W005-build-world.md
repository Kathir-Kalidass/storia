# W005: Build World — Prompt Guidance

## Purpose
Create or expand world elements: locations, kingdoms, magic systems, cultures, history.

## Element Types
- **Location**: Geography, climate, notable features, inhabitants
- **Kingdom/Political Entity**: Rulers, factions, economy, laws
- **Magic System**: Rules, costs, limitations, schools of magic
- **Culture**: Customs, traditions, social structure, taboos
- **Religion/Philosophy**: Beliefs, deities, clergy, rituals
- **History**: Key events, eras, founding myths

## Consistency Rules
- New elements must not contradict existing world state
- Magic systems must have clear costs and limitations
- Cultures must be internally consistent
- Historical events must respect established timeline
