# W001: Start New Story — Prompt Guidance

## Purpose
Initialize a new story project with metadata, DNA, and empty state sections.

## Before Writing
1. Ask the user for: title, genre(s), language, tone, target audience
2. Load the default persona for the selected genre
3. Create the Story State with initial metadata

## During Writing
Focus on establishing:
- Genre-appropriate tone and style
- Central thematic questions
- Reader promises implied by the genre choice

## After Writing
1. Verify that all required metadata fields are populated
2. Commit the initialized state
3. Suggest next step: build characters, build world, or plan the novel
