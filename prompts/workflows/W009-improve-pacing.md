# W009: Improve Pacing — Prompt Guidance

## Purpose
Adjust story pacing — scene length, tension curve, action/reflection balance.

## Pacing Levers
- **Sentence length**: Short for tension, long for reflection
- **Paragraph density**: Dense for action, sparse for quiet moments
- **Dialogue ratio**: More dialogue speeds up, more narration slows down
- **Scene length**: Split long scenes, merge very short ones
- **Tension**: Should generally rise toward act breaks

## Constraints
- Don't remove essential plot information
- Preserve character voice and tone
- Maintain all plot beats — only adjust delivery
