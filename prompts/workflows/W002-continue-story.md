# W002: Continue Story — Prompt Guidance

## Purpose
Generate the next narrative segment — chapter, scene, or continuation.

## Before Writing
1. Load active state and identify the current position in the story
2. Run Guide modules: knowledge boundaries, character voice, scene goal, timeline, physical state, story DNA
3. Compile constraints from active persona configuration

## During Writing
- Maintain character voice consistency
- Respect knowledge boundaries (POV character can only know what they've learned)
- Advance at least one active plot thread or subplot
- Follow the established tone and style from Story DNA

## After Writing
1. Run Synthesizer to extract state changes from the generated text
2. Run Verify modules: continuity, pacing, emotional arc, prose rhythm
3. Diff and commit the updated state
4. Optimize active state for next context window
