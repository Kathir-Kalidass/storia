# W011: Rewrite Scene — Prompt Guidance

## Purpose
Rewrite an existing scene with a new approach, tone, or content direction.

## Process
1. Archive the original scene (preserved for rollback)
2. Analyze the scene's purpose in the current state
3. Write the new version with the requested changes
4. Verify the rewrite doesn't break continuity with surrounding scenes

## Constraints
- Preserve all plot-relevant information from the original
- Maintain character voice consistency
- Ensure the new version connects logically to adjacent scenes
