# Workflow W002: Continue Story

## Intent
Resume an existing story — load state, generate next narrative content, synthesize changes, validate, commit.

## Triggers
- "continue", "next chapter", "resume", "next scene", "write next"

## Pipeline
1. **state-manager** → `load(storyId)` — pre-condition: story exists; on failure: stop
2. **validator** → `validate(state)` — pre-flight integrity check; on failure: flag, offer repair
3. **persona-engine** → `resolve(genre, language, state.metadata.active_personas)` — load current persona stack; on failure: fallback
4. **narrative-intelligence** → `guide(state, persona)` — constrained generation guidance; on failure: rollback
5. **creative** → `generate(scene, constraints)` — produce next narrative text; on failure: rollback
6. **synthesizer** → `synthesize(text, sceneId, state)` — extract structured changes; on failure: rollback
7. **synthesizer** → `mergeIntoState(changes, state)` — apply confidence-scored updates; on failure: flag
8. **validator** → `validate(state)` — post-write integrity; on failure: flag
9. **diff-engine** → `compute(oldState, newState)` — record what changed; on failure: flag
10. **state-manager** → `write(storyId, state, 'scene_completed')` — persist; on failure: stop
11. **optimizer** → `optimize(state, storyDir)` — compact and enforce budgets; on failure: flag

## Output
- Generated narrative text
- Updated state with committed changes
- Summary of what changed (diff)
