# Workflow W005: Build World

## Intent
Create or expand world elements — geography, kingdoms, magic systems, cultures, history.

## Triggers
- "worldbuild", "build world", "create world", "design world", "kingdom", "magic system"

## Pipeline
1. **state-manager** → `load(storyId)` — load current state; on failure: warn
2. **persona-engine** → `resolve(genre, language, {primary: 'worldbuilder'})` — load worldbuilding persona; on failure: fallback
3. **creative** → `generate('world', genre, existingWorld)` — produce world element; on failure: rollback
4. **synthesizer** → `synthesize(element, 'world', state)` — extract structured world data; on failure: rollback
5. **validator** → `validate(state)` — check world consistency; on failure: flag
6. **diff-engine** → `compute(oldState, newState)` — record addition; on failure: flag
7. **state-manager** → `write(storyId, state, 'world_updated')` — persist; on failure: stop
8. **optimizer** → `optimize(state, storyDir)` — compact; on failure: flag

## Output
- World element (location, kingdom, magic system, etc.)
- World state updated in Story State
