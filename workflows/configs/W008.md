# Workflow W008: Improve Dialogue

## Intent
Enhance dialogue quality — character voice consistency, subtext, pacing, attribution variety.

## Triggers
- "improve dialogue", "fix dialogue", "dialogue feels", "better conversation"

## Pipeline
1. **state-manager** → `load(storyId)` — load state; on failure: stop
2. **persona-engine** → `resolve(genre, language, {primary: 'dialogue-coach'})` — load dialogue persona; on failure: fallback
3. **narrative-intelligence** → `guide(state, persona, 'dialogue')` — identify dialogue sections; on failure: flag
4. **creative** → `generate('dialogue', targetScene, constraints)` — rewrite dialogue; on failure: rollback
5. **synthesizer** → `synthesize(rewritten, sceneId, state)` — extract changes; on failure: rollback
6. **validator** → `validate(state)` — check voice consistency; on failure: flag
7. **diff-engine** → `compute(oldState, newState)` — record changes; on failure: flag
8. **state-manager** → `write(storyId, state, 'dialogue_improved')` — persist; on failure: stop
9. **optimizer** → `optimize(state, storyDir)` — compact; on failure: flag

## Output
- Rewritten dialogue with attribution improvements
- Character voice consistency verified
