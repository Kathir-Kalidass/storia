# Workflow W001: Start New Story

## Intent
Begin a new story project — create story state, initialize metadata, load initial personas.

## Triggers
- "start a new story", "begin a new novel", "new project", "write a story"

## Pipeline
1. **state-manager** → `initialize(storiaDir)` — ensure base directory exists; on failure: stop
2. **orchestrator** → `createStory(title, genre, language, options)` — create active state + archive dirs; on failure: stop
3. **persona-engine** → `resolve(genre, language, options.personas)` — resolve primary persona stack; on failure: fallback to default
4. **state-manager** → `write(storyId, state, 'story_created')` — persist initialized state; on failure: stop
5. **optimizer** → `optimize(state, storyDir)` — compact initial state; on failure: flag

## Output
- New story ID with initialized active state
- Selected persona configuration
- Story metadata summary
