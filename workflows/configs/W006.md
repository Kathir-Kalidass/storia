# Workflow W006: Review Chapter

## Intent
Analyze and provide feedback on written content — check quality, consistency, pacing, character voice.

## Triggers
- "review", "check chapter", "analyze", "feedback", "read chapter"

## Pipeline
1. **state-manager** → `load(storyId)` — load current state; on failure: stop
2. **persona-engine** → `resolve(genre, language, {primary: 'critic'})` — load review persona; on failure: fallback
3. **narrative-intelligence** → `verify(state, chapterRef)` — run verification checks; on failure: continue with partial results
4. **validator** → `validate(state)` — integrity check; on failure: flag
5. **diff-engine** → `getHistory()` — review recent changes; on failure: flag

## Output
- Verification report with issues, suggestions, and quality score
- No state changes (read-only analysis)
