# Workflow W003: Plan Novel

## Intent
Create or revise a story outline — structure acts, plan scenes, establish narrative arc.

## Triggers
- "plan", "outline", "structure", "plot a", "story architecture"

## Pipeline
1. **state-manager** → `load(storyId)` — load existing state if resuming; on failure: warn, proceed fresh
2. **persona-engine** → `resolve(genre, language, {primary: 'story-architect'})` — load planning persona; on failure: fallback
3. **narrative-intelligence** → `reason(state, persona, 'plot')` — generate act/scene structure; on failure: rollback
4. **synthesizer** → `synthesize(plan, 'plan', state)` — extract structured plot data; on failure: flag
5. **synthesizer** → `mergeIntoState(changes, state)` — apply plot state; on failure: flag
6. **validator** → `validate(state)` — check plan consistency; on failure: flag
7. **state-manager** → `write(storyId, state, 'plan_created')` — persist; on failure: stop
8. **optimizer** → `optimize(state, storyDir)` — compact; on failure: flag

## Output
- Story outline (acts, chapters, key scenes)
- Updated plot state in Story State
