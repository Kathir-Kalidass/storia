# Workflow W004: Build Character

## Intent
Create or design a new character profile — personality, backstory, appearance, arc.

## Triggers
- "create character", "design character", "build character", "character profile", "new character"

## Pipeline
1. **state-manager** → `load(storyId)` — load current story state; on failure: warn
2. **persona-engine** → `resolve(genre, language, {primary: 'character-designer'})` — load character design persona; on failure: fallback
3. **creative** → `generate('character', genre, existingChars)` — produce character profile; on failure: rollback
4. **synthesizer** → `synthesize(profile, 'character', state)` — extract character data; on failure: rollback
5. **validator** → `validate(state)` — check for duplicate names, invalid refs; on failure: flag
6. **diff-engine** → `compute(oldState, newState)` — record addition; on failure: flag
7. **state-manager** → `write(storyId, state, 'character_created')` — persist; on failure: stop
8. **optimizer** → `optimize(state, storyDir)` — compact; on failure: flag

## Output
- Character profile (name, role, traits, backstory, arc)
- Character added to Story State
