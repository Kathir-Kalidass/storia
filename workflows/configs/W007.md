# Workflow W007: Fix Continuity

## Intent
Identify and resolve continuity errors — character state conflicts, timeline paradoxes, world inconsistencies.

## Triggers
- "fix continuity", "fix plot hole", "continuity error", "contradiction"

## Pipeline
1. **state-manager** → `load(storyId)` — load state; on failure: stop
2. **validator** → `validate(state)` — full integrity scan; on failure: continue (errors expected)
3. **diff-engine** → `getHistory()` — examine recent revisions for origin; on failure: flag
4. **narrative-intelligence** → `reason(state, 'continuity')` — propose fix plan; on failure: rollback
5. **creative** → `generate('fix', plan, state)` — produce corrected content; on failure: rollback
6. **synthesizer** → `synthesize(fix, 'fix', state)` — extract corrections; on failure: rollback
7. **validator** → `validate(state)` — verify fix resolved errors; on failure: repeat or flag
8. **diff-engine** → `compute(oldState, newState)` — record fix; on failure: flag
9. **state-manager** → `write(storyId, state, 'continuity_fixed')` — persist; on failure: stop
10. **optimizer** → `optimize(state, storyDir)` — compact; on failure: flag

## Output
- Continuity error list with resolutions
- Updated state with fixes applied
