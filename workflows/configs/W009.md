# Workflow W009: Improve Pacing

## Intent
Adjust story pacing — scene length, tension curve, action/reflection balance.

## Triggers
- "fix pacing", "too slow", "too fast", "improve pacing"

## Pipeline
1. **state-manager** → `load(storyId)` — load state; on failure: stop
2. **persona-engine** → `resolve(genre, language, {primary: 'pacing-editor'})` — load pacing persona; on failure: fallback
3. **narrative-intelligence** → `verify(state, targetScene, 'pacing')` — analyze pacing metrics; on failure: flag
4. **creative** → `generate('pacing-fix', analysis, state)` — restructure scene; on failure: rollback
5. **synthesizer** → `synthesize(restructured, sceneId, state)` — extract changes; on failure: rollback
6. **validator** → `validate(state)` — check consistency after restructure; on failure: flag
7. **diff-engine** → `compute(oldState, newState)` — record changes; on failure: flag
8. **state-manager** → `write(storyId, state, 'pacing_adjusted')` — persist; on failure: stop
9. **optimizer** → `optimize(state, storyDir)` — compact; on failure: flag

## Output
- Pacing analysis report
- Restructured scene with improved pacing
