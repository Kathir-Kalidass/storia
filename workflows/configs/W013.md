# Workflow W013: Expand Scene

## Intent
Add detail, length, or depth to an existing scene — description, dialogue, action, internal monologue.

## Triggers
- "expand", "add detail", "lengthen", "flesh out"

## Pipeline
1. **state-manager** → `load(storyId)` — load state; on failure: stop
2. **state-manager** → `archiveScene(storyId, sceneId)` — backup original; on failure: stop
3. **persona-engine** → `resolve(genre, language, {primary: 'expander'})` — load expansion persona; on failure: fallback
4. **creative** → `generate('expansion', sceneId, targetLength)` — produce expanded scene; on failure: rollback
5. **synthesizer** → `synthesize(expanded, sceneId, state)` — extract changes; on failure: rollback
6. **validator** → `validate(state)` — consistency check; on failure: flag
7. **diff-engine** → `compute(oldState, newState)` — record expansion; on failure: flag
8. **state-manager** → `write(storyId, state, 'scene_expanded')` — persist; on failure: stop
9. **optimizer** → `optimize(state, storyDir)` — compact; on failure: flag

## Output
- Expanded scene with added detail
- Original preserved in archive
