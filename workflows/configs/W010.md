# Workflow W010: Generate Ending

## Intent
Write or revise the ending of a story — resolve arcs, answer mysteries, deliver emotional payoff.

## Triggers
- "ending", "finale", "conclude", "finish story", "write ending"

## Pipeline
1. **state-manager** → `load(storyId)` — load state; on failure: stop
2. **persona-engine** → `resolve(genre, language, {primary: 'ending-specialist'})` — load ending persona; on failure: fallback
3. **narrative-intelligence** → `reason(state, 'ending')` — analyze open arcs, promises, mysteries; on failure: rollback
4. **creative** → `generate('ending', analysis, state)` — produce ending text; on failure: rollback
5. **narrative-intelligence** → `verify(state, endingText, 'satisfaction')` — check ending satisfaction; on failure: flag
6. **synthesizer** → `synthesize(ending, sceneId, state)` — extract changes; on failure: rollback
7. **validator** → `validate(state)` — post-ending consistency; on failure: flag
8. **diff-engine** → `compute(oldState, newState)` — record; on failure: flag
9. **state-manager** → `write(storyId, state, 'ending_generated')` — persist; on failure: stop
10. **optimizer** → `optimize(state, storyDir)` — compact; on failure: flag

## Output
- Generated ending narrative
- Updated story metadata (status → complete)
