# Workflow W016: Prepare Publication

## Intent
Final checks and preparation for publishing — editing pass, readiness checklist, marketing materials.

## Triggers
- "publish", "publication", "ready to publish", "prepare for publishing", "final check"

## Pipeline
1. **state-manager** → `load(storyId)` — load final state; on failure: stop
2. **persona-engine** → `resolve(genre, language, {primary: 'publishing-editor'})` — load publishing persona; on failure: fallback
3. **narrative-intelligence** → `verify(state, null, 'readiness')` — comprehensive readiness check; on failure: flag
4. **validator** → `validate(state)` — final integrity scan; on failure: flag
5. **narrative-intelligence** → `reason(state, 'publishing')` — generate blurb, query letter, synopsis; on failure: continue
6. **diff-engine** → `getHistory()` — compile revision history; on failure: flag
7. **state-manager** → `write(storyId, state, 'ready_for_publication')` — update status; on failure: stop
8. **optimizer** → `optimize(state, storyDir)` — compact for export; on failure: flag

## Output
- Publishing readiness report with score
- Marketing materials (blurb, synopsis, query letter)
- Final integrity verification
