# Workflow W011: Rewrite Scene

## Intent
Rewrite or redraft an existing scene with new approach, tone, or content.

## Triggers
- "rewrite", "redraft", "try again", "rewrite scene"

## Pipeline
1. **state-manager** → `load(storyId)` — load state; on failure: stop
2. **state-manager** → `archiveScene(storyId, sceneId)` — backup current scene; on failure: stop
3. **persona-engine** → `resolve(genre, language, state.metadata.active_personas)` — load personas; on failure: fallback
4. **creative** → `generate('scene', sceneId, constraints)` — produce new scene; on failure: rollback
5. **synthesizer** → `synthesize(rewritten, sceneId, state)` — extract changes; on failure: rollback
6. **validator** → `validate(state)` — integrity check; on failure: flag
7. **diff-engine** → `compute(oldState, newState)` — record rewrite diff; on failure: flag
8. **state-manager** → `write(storyId, state, 'scene_rewritten')` — persist; on failure: stop
9. **optimizer** → `optimize(state, storyDir)` — compact; on failure: flag

## Output
- Rewritten scene text
- Original scene preserved in archive
- Diff showing what changed
