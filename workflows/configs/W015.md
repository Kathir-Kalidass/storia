# Workflow W015: Create Series

## Intent
Build a series bible or plan for a multi-book story — cross-book arcs, series continuity, world evolution.

## Triggers
- "sequel", "series", "series bible", "next book"

## Pipeline
1. **state-manager** → `load(storyId)` — load existing state; on failure: warn
2. **persona-engine** → `resolve(genre, language, {primary: 'series-planner'})` — load series persona; on failure: fallback
3. **narrative-intelligence** → `reason(state, 'series')` — analyze cross-book arcs, character evolution; on failure: rollback
4. **creative** → `generate('series-bible', analysis, state)` — produce series bible; on failure: rollback
5. **synthesizer** → `synthesize(bible, 'series', state)` — extract series data; on failure: rollback
6. **validator** → `validate(state)` — check series consistency; on failure: flag
7. **diff-engine** → `compute(oldState, newState)` — record; on failure: flag
8. **state-manager** → `write(storyId, state, 'series_bible_created')` — persist; on failure: stop
9. **optimizer** → `optimize(state, storyDir)` — compact; on failure: flag

## Output
- Series bible document
- Cross-book arc definitions in state
