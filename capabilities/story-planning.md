# Capability: Story Planning

## Description
Provides high-level narrative architecture design including act structure, plot sequencing, theme mapping, and foreshadowing blueprints. Enables full novel outlining and series bible creation for multi-book arcs.

## Activation Triggers
"plan a novel", "outline a story", "create plot", "story structure", "start a new story", "begin a novel", "new project", "plan a sequel", "series bible", "series planning"

## Supported Workflows
W001 — Start New Story, W003 — Plan Novel, W015 — Create Sequel / Series Bible

## Preferred Personas
Primary: Novelist, Plot Engineer. Secondary: Foreshadow Specialist, Mystery Planner, Character Growth Architect. Style: Literary or genre-appropriate.

## Engines Invoked
Runtime Engine — intent detection, workflow routing, persona loading. Narrative Intelligence (Reason) — Story Architect, Plot Planner, Theme Planner, Conflict Generator, Foreshadowing Planner, Mystery Designer, Genre Rule Engine. Creative Engine — Title Generator. Persona Engine — persona composition and configuration delta. Memory Engine — state persistence.

## Input Requirements
Story Metadata (genre, language, audience). For sequels: full Story State from completed book.

## Output
Story Blueprint (act structure, chapter outline, character arcs, theme map, foreshadowing plan, title suggestions) or Series Bible (sequel blueprint, ongoing arcs, world evolution).

## Constraints
Cannot generate prose — only structural plans. Requires user approval before state commitment. Genre must be specified; otherwise falls back to nearest supported genre.
