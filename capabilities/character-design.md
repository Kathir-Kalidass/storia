# Capability: Character Design

## Description
Creates complete character profiles with psychology, voice, appearance, backstory, relationships, and growth arcs. Generates characters that are distinct, internally motivated, and properly integrated into the story's world and timeline.

## Activation Triggers
"create a character", "design character", "build a persona", "character profile", "create a villain", "build an antagonist", "develop a character arc"

## Supported Workflows
W004 — Build Character

## Preferred Personas
Primary: Character Psychologist. Secondary: Character Growth Architect, Villain Creator, Relationship Architect, Backstory Generator, Anti-Hero Designer.

## Engines Invoked
Runtime Engine — workflow routing. Creative Engine — Character Creator, Backstory Generator, Dialogue Creator, Relationship Architect. Narrative Intelligence (Reason + Guide) — Character Psychology, Character Voice Lock. Persona Engine — character-focused persona composition. Memory Engine — state persistence of Character State.

## Input Requirements
Story Metadata (genre, setting for contextual alignment). Existing Character State and World State for coherence with established elements.

## Output
Character Profile: identity (name, aliases, appearance), psychology (motivation, fear, flaw, growth trajectory), voice profile (vocabulary tier, dialect markers, humor style, signature phrases), backstory (formative events, secrets), relationships (connections to existing characters with dynamics), arc plan (beginning → middle → end), and sample dialogue.

## Constraints
Each character must have clear motivation, fear, and flaw. Voice profile must be distinct from existing characters (duplicate archetypes flagged). Backstory must be consistent with world timeline. Relationships must reference valid existing character IDs. Profile completeness enforced — gaps flagged for user input.
