# Capability: Editing

## Description
Multi-pass editorial analysis covering developmental structure, line-level prose polish, copy editing, and proofreading. Prepares manuscript for publication by identifying issues at every layer from plot architecture to typographical errors.

## Activation Triggers
"edit my story", "developmental edit", "line edit", "copy edit", "proofread", "prepare for publishing", "final check", "review manuscript"

## Supported Workflows
W016 — Prepare Publication

## Preferred Personas
Primary: Developmental Editor. Secondary: Line Editor, Copy Editor, Proofreader. Additional: Market Analyst (for market alignment).

## Engines Invoked
Runtime Engine — workflow routing. Publishing Engine — Development Editing (structural feedback, plot pacing, character arcs), Line Editing (sentence clarity, flow, word choice), Copy Editing (grammar, punctuation, consistency, style guide), Proofreading (final error pass). Verification Engine — Grammar check, Tone check, Prose Rhythm check, Reader Experience check. Persona Engine — editorial persona composition. Memory Engine — state metadata updates.

## Input Requirements
Full narrative text (completed manuscript). Full Story State (all sections). Story DNA. Genre and audience metadata.

## Output
Multi-layer edit report: developmental feedback (structure, pacing, arcs), line edit suggestions (sentence-level), copy edit corrections (grammar, consistency), proofreading flags (typos, formatting), overall quality score, and Publishing Readiness checklist completion status.

## Constraints
Requires complete manuscript — partial submissions flagged with completion gaps. Publishing Readiness score must reach >= 80 for passage. Critical issues block publishing readiness. Genre convention violations flagged with severity; author chooses resolution.
