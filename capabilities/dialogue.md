# Capability: Dialogue

## Description
Analyzes and improves character dialogue for authenticity, subtext, attribution variety, and voice consistency. Ensures each character speaks according to their established Voice Profile and that exchanges serve dramatic purpose beyond information transfer.

## Activation Triggers
"improve dialogue", "fix dialogue", "better conversation", "dialogue feels flat", "dialogue sounds unnatural"

## Supported Workflows
W008 — Improve Dialogue

## Preferred Personas
Primary: Dialogue Dramatist, Dialogue Personality Designer. Secondary: Character Psychologist. Style: Cinematic.

## Engines Invoked
Runtime Engine — intent detection and workflow routing. Narrative Intelligence (Guide + Verify) — Character Voice Lock, Dialogue Coach. Persona Engine — persona composition for dialogue sensitivity. Verification Engine — Dialogue check (attribution variety, subtext presence, character voice lock).

## Input Requirements
Chapter/scene text containing dialogue passages. Character State with Voice Profiles (vocabulary tier, sentence length, dialect markers, humor style, signature phrases) for each speaking character.

## Output
Dialogue Improvement Suggestions per exchange: identified issue (flat exchange, repetitive tag, missing subtext, voice drift), suggested revision, and expected effect on reader experience.

## Constraints
Read-only analysis — does not modify text directly. Cannot improve dialogue for characters without a Voice Profile (flags and suggests creation). Attribution variety must not be artificially inflated. Respects persona conflict resolution for style overrides.
